# MailBlast · 产品介绍

> 用**你自己的邮箱**，把同一封信准确地发给一群人。
> 本地运行、数据留在自己的电脑里，不经过任何第三方发信通道。

---

## 它解决什么问题

你需要向几十到上千个收件人发出内容相似、但又要带点个人称呼的邮件——通知、邀请、回访、资料分发。用网页邮箱手动发不现实，接第三方群发平台意味着把收件人名单和邮箱授权码交给别人，还常按发信量计费、有品牌露出。

MailBlast 的做法是：**发信通道仍是你自己的 SMTP 邮箱**（Gmail / QQ / 163 / Outlook 或任意 SMTP 服务），软件只负责把编排、节奏、个性化和统计做好。名单和凭据存在本机 SQLite 里，不上传。

---

## 核心能力

### 1. 发送节奏可调控，避免"机器味"

- **随机间隔**：在设定的最小/最大值之间随机等待，而不是固定秒数连发
- **批量重连**：每发送 N 封自动断开重连，避免单条连接发太多被服务商限流
- **失败自动重试**：可配重试次数，采用指数退避；失败的收件人会单独归集，支持**只重发失败名单**
- **随时可控**：开始后可暂停、继续、停止

### 2. 多账号轮换

配置多个发件账号后按序轮流发送（round-robin），把单次任务的压力分散到多个邮箱上。

### 3. 个性化内容

- 内置变量：`%TO_NAME%`、`%TO_EMAIL%`、`%SENDER_NAME%`、`%CURRENT_DATE%`、`%CURRENT_TIME%`
- 支持**自定义变量**，按收件人逐条替换
- HTML 正文（内置 HTML 源码编辑器），支持附件，单封上限 50MB
- 附件 MIME 类型自动识别，未知类型安全回退

### 4. 收件人管理

- **Excel 导入**（单次最多 1000 个邮箱）、**复制粘贴自动解析**、手动逐个添加
- 列表内可直接编辑、删除
- 自动去重、格式校验；对已声明不接受邮件的域名（NullMX）自动跳过
- 提供 Excel 导入模板下载

### 5. 发件账号管理

- 账号增删改查，**CSV 批量导入 / 导出**（兼容多种表头写法）
- **一键连接测试**，实测连通性并给出建议端口
- 端口策略自动适配：465 → SMTP_SSL，587/25 → STARTTLS；不通时自动尝试候选端口

### 6. 过程实时可见

- 进度实时推送（约 0.8 秒刷新一次），当前收件人、成功/失败数即时更新
- 发送结束后可查看完整记录

### 7. 发送记录与统计

- 历史发送记录、成功率、近 7 / 14 天趋势
- 日志可导出 CSV，失败名单可导出后针对性重发

### 8. 网络环境适配

- 代理支持：HTTP/HTTPS（CONNECT）与 SOCKS5 / SOCKS4，均支持带用户名密码
- 适配企业内网、代理出口等场景

### 9. 数据留在本地

- 全部数据存放在本机 SQLite，数据目录按平台规范放置：

  | 平台 | 数据目录 |
  |---|---|
  | Windows | `%APPDATA%\MailBlast` |
  | macOS | `~/Library/Application Support/MailBlast` |
  | Linux | `~/.local/share/MailBlast` |

## 快速上手

1. 获取邮箱的 SMTP 授权码与正确端口（Gmail 需开启应用专用密码，QQ 邮箱需开启 SMTP 服务）
2. 启动程序，浏览器打开 `http://127.0.0.1:5001`
3. 在「发件账号」中添加账号，用「连接测试」确认可用
4. 在「收件人列表」中导入 Excel 或直接粘贴名单
5. 在「邮件发送」中写正文（可用变量），按需添加附件
6. 在「发送设置」中调整间隔、重试、批量重连
7. 点击发送，实时查看进度

## 当前版本说明

为保证预期一致，以下为当前版本的实际情况：

- **不含永久免费**：未激活状态下核心功能不可用（可关注公众号领取 3 天试用，或参与闲鱼试卖免费领取激活码，见上文两个活动章节）
- **不做退信（bounce）处理**：SMTP 拒绝的收件人会记为失败，但不解析退信邮件
- **按域名/失败自动切换账号**：当前为固定顺序轮换，不按失败情况动态切换
- **SMTP 证书校验**：为兼容各类服务商与代理链路，SMTP 连接采用宽松证书策略（不校验主机名与证书链）
- **授权码本地加密**：已实现但处于灰度阶段，默认关闭
- **使用统计**：程序内置匿名使用统计上报（Matomo），默认开启
